description: 从用户目标出发实现界面，并在真实页面验证关键路径。
activation:
  mode: task
  instruction: 设计或修改用户可见界面、交互、布局或视觉样式时读取。
---
先确认主要用户任务、信息层级与现有设计语言。小而明确的改动直接完成；多种方案会显著改变使用方式时，给出可比较的具体方案再决定。

保持布局在窄屏和常用窗口可用，处理加载、空白、失败及成功状态。交互支持语义化控件、键盘操作、可见焦点与足够对比度；只在项目支持主题时验证对应主题。

打开本次检出的真实页面或应用，完成受影响的用户路径，检查控制台与网络异常。验证显示的是当前构建；截图用于说明观察，不能替代交互验证。无法启动时报告准确限制。

项目有多个入口或客户端时检查同一能力的对应实现，按真实职责同步；不要假定每个项目都需要原型、桌面和 Web 三端。
