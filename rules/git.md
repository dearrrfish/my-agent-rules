title: 阶段提交与工作区收尾
description: 完成目标或阶段任务后自动创建本地 commit，推送仍须明确授权。
activation:
  mode: task
  instruction: 修改仓库文件、完成目标或阶段任务、创建提交或管理工作树时读取。
---
任务开始查看 git status，识别本任务改动与已有或并发工作。完成可交付目标或明确阶段时，完成相称验证、审阅最终 diff，自动创建本地 commit。只读任务或没有有效文件变化时不创建空提交。

只暂存本任务拥有的文件或 hunk，提交前审阅 staged diff。无法可靠分离混合改动时先说明具体冲突；不能把用户改动一并提交。遵循仓库提交格式与署名要求，提交信息描述最终结果，交付报告 commit hash 和实际验证。

默认分支需要隔离时先建立任务分支。未经明确要求不 push、force push、改写已共享历史或合并；本地 commit 的授权不自动覆盖这些操作。凭据和临时产物不进入提交。

只清理确认属于本任务的 worktree、分支、预览服务和构建目录；删除前确认成果已安全保存在提交或指定位置，不删除仍有未归属改动的工作树。

行为示例：完成规则库首版并验证后自动本地提交；没有获得推送授权时只交付本地 commit，不创建远端发布。
