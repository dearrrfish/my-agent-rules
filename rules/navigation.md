  mode: task
  instruction: 开始陌生仓库任务、定位模块或发现上下文不足时读取。
---
先读仓库入口和当前目录约定，再搜索关键行为、调用方与相邻测试。优先使用文件清单、符号和关键词定位，只打开完成当前任务需要的章节与行段。

全局入口保留少量常驻约束与条件明确的阅读路线；细则放在所属主题或目录，只维护一份权威正文。链接写出触发条件和具体目标，不能假定宿主会自动读取普通 Markdown 链接。

遇到冲突时区分目标规范、实际实现与历史记录；以当前有效约定和可验证行为判断，不把旧实施报告当作当前事实。定位已足够支撑改动时停止扩展阅读。

行为示例：修复解析器先看入口调用、解析实现与失败测试，不通读整棵 docs 目录。
