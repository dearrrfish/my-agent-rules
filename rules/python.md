遵循项目已有 Python 版本、环境管理、格式和类型约定。公共接口给出清楚的输入输出，外部数据进入领域逻辑前校验；不要仅靠类型注解假定运行时输入正确。

文件、进程和网络资源使用上下文管理或明确清理，文本编码显式或与项目约定一致。仅捕获有恢复策略的异常，保留异常链和原始上下文，不静默吞错。

测试与工具运行在项目环境内。读取不可信归档或数据时避免从其目录启动解释器，防止同名模块被意外导入；调用外部程序使用参数数组。
